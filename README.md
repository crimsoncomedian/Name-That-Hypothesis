# Name That Hypothesis

Endless practice for statistics students: read a freshly generated scenario, then choose the null hypothesis and the alternative hypothesis. Scenarios come from 40 situations (20 about an average, 20 about a proportion) with random values, directions and wording. Wrong answers get feedback on the classic mistakes.

Live page: https://crimsoncomedian.github.io/Name-That-Hypothesis/

One self-contained file (`index.html`), no build step and no running cost.
